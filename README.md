# Sistema de Administración de Condominio Vista Verde
Proyecto final del curso Programación I desarrollado en Java Swing.


## Descripción
Sistema de escritorio que permite administrar el cobro y control de cuotas de mantenimiento de las 30 casas del condominio Vista Verde.

## Instrucciones para ejecutar el proyecto

1. Clonar el repositorio desde GitHub.
2. Abrir el proyecto en NetBeans.
3. Verificar que Java JDK 25 esté instalada.
4. Esperar a que Maven descargue automáticamente las dependencias del proyecto.
5. Ejecutar la clase principal del sistema.
   

## Dependencias Utilizadas
